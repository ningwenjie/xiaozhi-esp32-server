1.启动MYSQL
sudo service mysql start

2.启动向量数据库
redis-stack-server -port 6379

3.启动api
cd /root/autodl-tmp/newtts/main/manager-api/
mvn spring-boot:run

4.启动智控台web
cd /root/autodl-tmp/newtts/main/manager-web
npm run serve


启动web服务后，同时也可以访问测试页：
https://u568363-a2aa-d6cc2d9d.nmb1.seetacloud.com:8443/test/test_page.html



5.启动语音服务器
conda activate llama
cd /root/autodl-tmp/newtts/main/server
python app.py


注意：语音服务器地址格式为：
wss://u568363-a2aa-d6cc2d9d.nmb1.seetacloud.com:8443/server


6.启动声纹服务器

conda activate voiceprint-api
cd /root/autodl-tmp/newtts/main/manager-web/voiceprint-api
python start_server.py
