# AI陪伴功能用户使用指南

## 功能概述

AI陪伴功能是为特殊儿童设计的引导式场景对话训练系统。通过配置化的对话流程，帮助儿童练习表达需求、情感和社交技能。

## 主要特性

- **场景配置化**：所有对话流程通过配置实现，无需编程
- **多轮对话**：支持复杂的多轮对话流程设计
- **智能判断**：AI判断儿童回答的准确性，自动调整教学策略
- **个性化**：记忆儿童姓名，提供个性化教学体验
- **动态步骤**：支持配置不固定数量的对话步骤

## 使用流程

### 1. 配置智能体

1. 登录管理后台
2. 进入"角色配置"页面
3. 在"场景配置"部分点击"配置场景对话"按钮
4. 系统会跳转到场景配置页面

### 2. 创建场景

1. 在场景配置页面点击"新建场景"
2. 填写场景基本信息：
   - **场景名称**：如"表达需求-口渴"
   - **场景类型**：选择"表达需求"、"问候"、"情感表达"或"指令执行"
   - **触发方式**：选择"语音触发"、"视觉触发"或"按键触发"
   - **难度等级**：1-5级，根据儿童能力选择
   - **目标年龄**：选择适合的年龄范围
3. 配置触发条件：
   - **语音触发**：输入关键词，如"渴了"、"口渴"、"喝水"
   - **视觉触发**：输入卡片编码
   - **按键触发**：输入按键代码
4. 保存场景配置

### 3. 配置对话步骤

1. 点击场景的"配置步骤"按钮
2. 在步骤配置页面添加对话步骤：
   - **步骤名称**：如"介绍表达需求"
   - **AI说的话**：输入AI要说的固定语句，支持使用`**{childName}**`替换儿童姓名
   - **期望回答**：输入期望的关键词和完整短语
   - **成功条件**：选择"完全匹配"、"部分匹配"或"关键词匹配"
   - **最大尝试次数**：设置允许的最大尝试次数
   - **失败提示**：输入当儿童回答错误时的提示语句
   - **手势提示**：选择适当的手势提示
   - **音效**：配置音效文件名
3. 可以导入步骤模板快速创建常用步骤
4. 调整步骤顺序
5. 保存步骤配置

### 4. 测试场景

1. 点击场景的"测试"按钮
2. 模拟儿童回答进行测试
3. 验证对话流程是否符合预期

### 5. 启用场景

1. 将场景状态设置为"启用"
2. 场景将在设备端生效

## 场景类型说明

### 表达需求 (express_needs)
帮助儿童练习表达基本需求，如口渴、饥饿、疲劳等。

**示例场景**：
- 口渴时如何表达
- 饥饿时如何表达
- 需要帮助时如何表达

### 问候 (greeting)
练习基本的问候和礼貌用语。

**示例场景**：
- 见面时的问候
- 分别时的告别
- 感谢和道歉

### 情感表达 (emotion)
学习表达各种情感和感受。

**示例场景**：
- 表达开心
- 表达难过
- 表达生气
- 表达害怕

### 指令执行 (instruction)
练习理解和执行简单指令。

**示例场景**：
- 跟随简单指令
- 理解动作指令
- 执行多步指令

## 触发方式说明

### 语音触发
通过语音关键词触发场景。儿童说出特定关键词时，系统自动启动对应的场景对话。

**配置示例**：
```json
["渴了", "口渴", "喝水"]
```

### 视觉触发
通过识别卡片或图片触发场景。儿童展示特定卡片时，系统自动启动对应的场景对话。

**配置示例**：
```json
["card_thirsty", "card_hungry"]
```

### 按键触发
通过物理按键触发场景。儿童按下特定按键时，系统自动启动对应的场景对话。

**配置示例**：
```json
["btn_express_needs", "btn_greeting"]
```

## 对话步骤配置

### 步骤类型

- **普通步骤**：常规对话步骤
- **开始步骤**：场景开始步骤
- **结束步骤**：场景结束步骤
- **分支步骤**：条件分支步骤

### 成功条件

- **完全匹配**：用户回答必须与期望答案完全一致
- **部分匹配**：用户回答包含期望的关键词即可
- **关键词匹配**：用户回答包含任意期望关键词即可

### 手势提示

- **指嘴巴**：指向嘴巴的手势
- **指肚子**：指向肚子的手势
- **指眼睛**：指向眼睛的手势
- **指腿**：指向腿的手势
- **拍手**：拍手的手势
- **挥手**：挥手的手势

2. 查看儿童的学习进度和表现
3. 分析成功率和学习时长

## 最佳实践

### 场景设计建议

1. **循序渐进**：从简单场景开始，逐步增加难度
2. **贴近生活**：选择儿童日常生活中常见的场景
3. **个性化**：根据儿童的具体情况定制场景
4. **多样化**：提供多种触发方式和表达方式

### 步骤配置建议

1. **清晰明确**：AI说的话要简单明了
2. **鼓励为主**：多使用鼓励性的语言
3. **耐心等待**：给儿童足够的思考和回答时间
4. **灵活调整**：根据儿童表现调整期望答案

### 测试建议

1. **全面测试**：测试各种可能的回答情况
2. **模拟真实**：模拟真实的儿童回答方式
3. **记录问题**：记录测试中发现的问题
4. **持续优化**：根据测试结果不断优化配置

## 故障排除

### 常见问题

1. **场景不触发**
   - 检查场景是否已启用
   - 检查触发条件配置是否正确
   - 检查设备端连接是否正常

2. **对话流程异常**
   - 检查步骤配置是否完整
   - 检查期望答案设置是否合理
   - 检查成功条件设置是否合适

3. **学习记录不保存**
   - 检查API连接是否正常
   - 检查数据库配置是否正确
   - 检查网络连接是否稳定
